# 贴云飞行 · Cloud Skimmer

驾驶自动开火的战机飞过六条航线，击落敌机，用金币改装机炮与护盾。前五关坚持 60 秒即可返航，最后一关要赶在旗舰撤离前击破它。

**[开始飞行](https://coredell16.github.io/cloud-skimmer/)**

## 六条航线

| 航线 | 怎么飞 |
| --- | --- |
| [01 珊瑚海岸](https://coredell16.github.io/cloud-skimmer/) | 在海岛之间练习急转，让敌弹擦过机翼来蓄能。 |
| [02 日落峡湾](https://coredell16.github.io/cloud-skimmer/?stage=2) | 留意两侧的预警，在敌机交叉切入前腾出位置。 |
| [03 极光前哨](https://coredell16.github.io/cloud-skimmer/?stage=3) | 沿着弹幕留下的缺口移动，同时留意普通敌机的射击。 |
| [04 雾港灯阵](https://coredell16.github.io/cloud-skimmer/?stage=4) | 金色虚线提前标出即将亮起的航道，及时切入暗区。 |
| [05 风暴航道](https://coredell16.github.io/cloud-skimmer/?stage=5) | 根据箭头判断横风方向，迎风移动，给自己留出躲弹的余地。 |
| [06 赤环旗舰](https://coredell16.github.io/cloud-skimmer/?stage=6) | 躲过扇射和瞄准齐射，核心变绿时对准射击。在 60 秒内击破旗舰。 |

六关均可直接进入。前五关返航后，可以在结算画面进入下一关。每关重新配备三架机体，得分和能量从零开始。

## 金币与装备

普通敌机掉落 3 金币，精英敌机掉落 6 金币，旗舰掉落 30 金币。连锁闪电击落的敌机也会计入。金币在击落时入账，即使坠机也能带回机库。

在标题或结算画面打开「装备机库」。例如，击落五架普通敌机就够买第一级机炮。每一档的金币花费如下。

| 装备 | 一级 | 二级 | 三级 | 效果 |
| --- | ---: | ---: | ---: | --- |
| 双联机炮 | 15 | 36 | 66 | 从每秒约 5.6 轮齐射逐级提升到 6.5、7.4、8.3 轮。 |
| 机体护盾 | 21 | 48 | — | 每提升一级可多抵挡一次伤害，每次起飞自动补满。 |

购买的装备从下次起飞生效。六关共用金币和装备，进度保存在当前浏览器。在线版和本地离线版分别存档。

## 怎样玩

- **电脑**　按 `Enter` 起飞，用 `WASD` 或方向键移动，按 `P` 暂停或继续。
- **手机**　点「开始飞行」，在飞行区域单指拖动。点倒计时旁的暂停键可以歇一会儿。
- **擦弹**　让敌弹擦过机翼，每次可得 25 分并充入 20% 能量。攒满后击落一架敌机，就能触发连锁闪电。

成功返航时，每架剩余机体额外奖励 200 分。每条航线分别在当前浏览器保存最高分，旧版成绩计入珊瑚海岸。

## 在本地运行

下载并解压仓库，或用 Git 克隆仓库。用浏览器打开根目录的 `index.html` 即可游玩，脚本、图片和字体随游戏一起提供。
