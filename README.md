# 贴云飞行 · Cloud Skimmer

驾驶一架自动开火的战机，在珊瑚海岸上空坚持 60 秒。急转时机翼先侧倾，镜头随后跟上，近处的云和远处的岛屿以不同速度掠过。

**[开始飞行](https://coredell16.github.io/cloud-skimmer/)**

## 怎样玩

- **电脑**　按 `Enter` 起飞，用 `WASD` 或方向键移动，按 `P` 暂停或继续。
- **手机**　点「开始飞行」，在飞行区域单指拖动。松手后飞机悬停，点倒计时旁的暂停键可以歇一会儿。
- **擦弹**　让敌弹擦过机翼，每次可得 25 分并充入 20% 能量。攒满后击落一架敌机，就能触发连锁闪电。

每局有三架机体。成功返航时，每架剩余机体额外奖励 200 分。最高分保存在当前浏览器中。

## 在本地运行

下载并解压仓库，或用 Git 克隆仓库。用浏览器打开根目录的 `index.html` 即可游玩，脚本、图片和字体随游戏一起提供。
